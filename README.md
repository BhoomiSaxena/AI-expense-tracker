# AI Expense Tracker & Financial Insights Assistant

## Overview

AI Expense Tracker & Financial Insights Assistant is an AI-powered financial management application that helps users track expenses, analyze spending patterns, and generate actionable financial insights. The system automates expense categorization, provides interactive visualizations, and enables data-driven budgeting decisions through an intuitive user interface.

---

## Features

- Upload and process expense data from CSV files
- Automatic expense categorization
- Monthly and category-wise spending analysis
- Interactive financial dashboard
- Budget tracking and monitoring
- Spending trend analysis
- Data visualization using charts and graphs
- Financial insights generation
- User-friendly Streamlit interface

---

## Technologies Used

- Python
- Pandas
- NumPy
- Streamlit
- Matplotlib
- Power BI
- Git & GitHub

---

## Project Workflow

1. User uploads expense data in CSV format.
2. Data is cleaned and processed using Pandas.
3. Transactions are categorized automatically.
4. Spending patterns and trends are analyzed.
5. Interactive charts and dashboards are generated.
6. Financial insights are presented to the user.

## Installation

### Clone the Repository

```bash
git clone https://github.com/BhoomiSaxena/AI-Expense-Tracker.git
cd AI-Expense-Tracker
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
streamlit run app.py
```
