# Personal Finance Guidance

## Spending Analysis Basics
- Always identify the top 1-2 spending categories first.
- Compare discretionary categories (food delivery, shopping, entertainment) against fixed essentials.
- Review month-over-month changes to detect lifestyle creep.

## Practical Budgeting Rules
- Use a simple split such as 50/30/20 (needs/wants/savings) as a starting point.
- If expenses are high, first reduce wants by 10-20% before touching essentials.
- Set category limits and track them weekly, not only at month-end.

## Managing Cash Flow
- Build an emergency fund for 3-6 months of essential expenses.
- Keep fixed bills and savings automated to avoid overspending.
- Before large purchases, apply a 24-hour waiting rule.

## Expense Reduction Ideas
- Food: limit ordering frequency and create a weekly spend cap.
- Transport: batch trips and use lower-cost options when possible.
- Subscriptions: cancel unused services every month.
- Shopping: buy from a list and avoid impulse purchases.
